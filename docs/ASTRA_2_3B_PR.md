Base **astra-2.3-editorial**, head **astra-2.3b-forecast-engine**; только Draft/staging-ревью. Бесплатный общий солнечный прогноз связан доминантой и содержит все разделы с прежним числом дня. Архив читается до генерации/доставки; повтор не списывает повторно. Есть standalone Worker и инструкция Dashboard.
