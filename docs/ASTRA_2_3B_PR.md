# Astra 2.3B: версионированный дневной движок и единый пакет за 4 ✨

Base astra-2.3-editorial (0d9ca44), head astra-2.3b-forecast-engine. Вместо независимых коротких фраз — структурированный полный бесплатный прогноз с доминантой, отношениями, работой, финансами, эмоциональным ритмом, прежним числом со смыслом и практическим итогом. Каталог: 12 знаков/48 профильных секций, 144 блока восьми тем, 9 пар значений числа, 24 руны, 12 символов/палитр и 24 совета. Тематическая ротация и совместимость справочных элементов не являются астрономическими вычислениями.

0023 добавляет immutable общий cache sign/day/ru и отдельный immutable unlock owner/day с price=4; триггеры атомарно фиксируют −4 и ledger с operation_id=NULL, reason forecast:extended. Старый CHECK операций не изменён. Повторы, новая версия/знак и Telegram errors читают сохранённый снимок без новой оплаты. Все входы и Cron используют один free-сервис. Удаление работает при FK OFF. Явный московский cutover сохраняет прежний free до следующей даты; без настройки/полной схемы 503. Single-file собирается Node core без npm.

sh scripts/test-2.3b.sh проходит: вся прежняя регрессия 2.0/2.1/2.2/2.3A; на B 30 legacy assertions + 28 hardening + 20 shell; 28 новых tests. Аудит 12×1 826 дат (2026–2030): 185–236 русских слов; 369 повторов без даты (~1,68%), максимум 3, нет повторов соседних тематических блоков. 20 конкурентных обработчиков и 20 SQLite-соединений дают один расход; fault injection/rollback, даты/версии/FK/доставка проверены. Есть реальные 12+4+2 образца и подробная инструкция семи SQL-шагов Dashboard.

Только кандидат для staging-ревью: Cloudflare/боты/remote SQL/webhook/секреты/production не менялись. Реальная D1/телефон/лимиты Free не проверены; публичная документация квот блокируется прокси, чисел гарантий тарифа нет. Текст конечного каталога требует редакционной поддержки, внешняя доставка exactly-once не обещана. Миграцию/тестовую установку выполняет только владелец после backup и проверки имён astra-staging-21-worker / astra-staging-21. Не мержить main автоматически.
