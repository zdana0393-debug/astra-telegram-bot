## Правило выполнения
**Строго последовательно**: TASK_01 (экономика, цены, HMAC abuse), TASK_02 (смысловая редактура гороскопа), TASK_03 (Cron и рассылка), TASK_04 (UI, Stars Terms, пользовательские сообщения), TASK_05 (интеграция, полная регрессия, release guide). ## Что оплачивается теперь
Утверждённые владельцем награды/Stars: см. \`ASTRA_2_4_PRESTAGING_PATCH_SPEC.md\`. Владелец ОТМЕНИЛ общее повышение тарифов. **Единственное повышение среди услуг — обычное трёхкарточное Таро с 3 до 5 ✨.** Все остальные услуги возвращаются к согласованным ценам до предыдущего увеличения; расширенный ежедневный прогноз 4 ✨ не меняется. - День по Europe/Moscow, бесплатный гороскоп с число дня неизменно \`hash(sign+day)%9+1\`, старые paid/free snapshots immutable, нет выдуманной реальной астрономии;

- Cloudflare Free CPU/D1/500MB бюджеты, тестировать после каждой фазы и обязательно на реальной staging позже;
