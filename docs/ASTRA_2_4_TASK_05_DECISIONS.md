# Решения владельца и границы готовности

**Технически подготовлено:** единый manual-only Worker, SQL0024–0027, UI/финансы/прогнозы и офлайн-проверки. **Не подтверждено:** ваша реальная D1/Cloudflare/Telegram, восстановление, CPU/квоты и законность хранения. Установки не было.

| Решение / доказательство | До чего необходимо | Текущий статус |
|---|---|---|
| Разрешение именно staging-установки и проверенная backup/restore копия | Любой remote SQL/деплой | Не получено/не выполнено разработчиком |
| Фактическая схема, неактивная0025, пауза всех writers | Миграции0024→27 | Не проверено удалённо |
| Поля/retention/уведомление/версия0028, nonce/revoke и SQL+send gate | Автоматическая доставка | Только предложение; код полностью запрещает отправку |
| Доказанное явное согласие старыхON | Получение ежедневных сообщений | Нет; староеON не доказательство |
| HMAC lawful basis, notice, индивидуальное согласие если оно нужно по выбранному основанию | Любое новое защищённое бонусное начисление | Публикация текста не заменяет решение |
| Ограниченный физический purge SLA, частота, backlog, backup retention и ключевая ротация | Правдивое обещание срока данных | Eligibility30дней проверен; платформа/график не проверены |
| Минимизация ID/заказов/долга, unresolved disputes, бессрочный charge fingerprint и возможность связывания | Поддержка/Stars/public privacy | Нужна оценка владельца; не объявлено анонимным/автоматически законным |
| Реальные support/Terms version/retention и dedicated test environment | Stars shopON | Не утверждены разработчиком; магазинOFF |
| Cloudflare CPU10ms, D1/HTTP50,rows_*,storage500MB,суточные квоты | Публичный допуск/рассылка/масштабирование | Только локальные модели, не реальные измерения |
| Будущая дата policy и compact, отдельно активация флагов | Новые награды/редакция | Не назначены автоматически |
| Production, webhook/Cron changes, реальные XTR, merge | Любое такое действие | Отдельное разрешение, сейчас отсутствует |

Оценка staging: **кандидат можно рассматривать только для ограниченной ручной установки после реального restore rehearsal, подтверждения схемы и явного разрешения владельца**. Это не утверждение, что сейчас уже выполнены условия безопасной установки. Общий /health=503 ожидаем из-за STOP-SHIP; manual_content_ready показывает лишь техническую готовность ручного пути.

Реальная рассылка запрещена compile-time и не включается переменной. Приложение сохраняет ограниченную служебную очистку; текущая работа не создаёт настоящего Trigger и не меняет уже развёрнутого бота. После согласования0028 нужны отдельная реализация, конкурентные тесты, бюджет и staging; её согласование не подразумевается одобрением текущего PR.
