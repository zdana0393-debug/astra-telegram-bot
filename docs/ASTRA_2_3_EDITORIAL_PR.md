# Astra 2.3, этап A: полная редактура пользовательских текстов

Base: astra-2.2-shell; head: astra-2.3-editorial. Самостоятельный release/ASTRA_2_3_EDITORIAL_WORKER.js сохраняет техническую основу 2.2. Переписаны старт, все страницы и состояния, 52 фразы прогноза, 44 трактовки, короткие/подробные FAQ, команда, статусы и внутренняя навигация. Основные шесть reply-названий, callbacks, SQL, алгоритмы/цены/бонусы не меняются.

На обычных страницах убраны детская театральность и постоянные объяснения легенды. Методология и FAQ сочетают правильные термины астрологии/нумерологии/Таро с фактическими Workers/D1/webhook/SQL/идемпотентностью; отсутствующие эфемеридные/натальные расчёты не выдаются за функции. Число дня — прежний хеш знака и даты, не цифровой корень. В команде сохранены GPT6 и консультант нужного профиля, добавлен инженер Elias Voss; FAQ честно описывает одного создателя с помощью ИИ и редакционные роли.

Проверка sh scripts/test-2.3-editorial.sh: вся база 2.0/2.1/2.2 зелёная; на editorial 30 регрессионных assertions, те же 28 hardening и 20 shell tests, плюс 14 новых текстовых/контрактных тестов, все passed. Из прежних ожиданий менялись только пользовательские тексты; денежные assertions сохранены. Проверены атомарность, повторы/отказы, удаление с FK OFF, SQL/callback-контракты, неизменность числа/выбора карт и дословная выдача сохранённого результата 2.2. Есть таблицы прежде→после, редакторская самооценка и инструкция проверки на тестовом Worker.

Это кандидат для редакционного ревью, без деплоя, новых миграций, remote SQL, webhook/Cron changes, секретов или изменений production. Полный новый движок гороскопа и расширенный платный прогноз — следующие отдельные задачи. Не объединять main автоматически.
