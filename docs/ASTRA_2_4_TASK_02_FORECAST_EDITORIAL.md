## Неприкосновенные механические правила
- Прогноз по **выбранному солнечному знаку и дате Europe/Moscow**. Это не реальные транзиты, не эфемериды и не личная натальная карта. Честность — точно следовать нашей версии символических правил и не заявлять астрономическую точность, которой нет.
- Остаются 12 знаков со своими стихиями, модальностями, управителями как традиционными соответствиями; тематическая 8-дневная ротация, совместимость selection по условиям и \`incompatible_with\`, директивы timing/contact, валидация отсутствия конфликтов, детерминированный seed, \`sign+date\`-дневной кэш, версия engine/catalog. Строго \`hash(sign+day)%9+1\` для бесплатного числа дня.
- Не менять уже выданный \`free_text\`, платный \`result_text\`, предыдущий \`extended_text\` / immutable forecast rows и сохранённые источники. При новом редакционном формате только новые даты/новые записи, с запланированным будущим content/engine cutover; не переинтерпретировать старую покупку.
- Не вводить платные LLM API, выдуманные реальные транзиты, абсолютные гарантии события или «98% точности». При несогласованных данных не подставлять красивую ложную фразу.

## Задача: смысловое редактирование, а не тупое сокращение
Текущий engine собирает для каждой секции \`unit.body + sign_lens.body (+modality_lens.body)\`. Сейчас это даёт канцелярит и повторы «Земля», «Меркурий», «форма», не единый смысл. Нужен проверяемый компактный semantic layer с той же исходной детерминированной логикой selection: выбирает ключевую мысль из валидных блоков и разные полезные интерпретации в 5–7 коротких строках, не противореча директивам, теме и знаку. Если редактируются каталоги, trace всех используемых источников сохранять; считать короткую полезность, а не число синонимов. Не добавлять вне механики произвольные указания — советы должны иметь явный тематический/профильный источник. \`source_tags\` и trace показывают, откуда взят тезис/совет; автоматический audit обнаруживает семантические противоречия.
- Пример формата: «🌙 ГОРОСКОП · дата / ♍ Знак», «✨ Главное», «💕 Отношения», «📚 Дела», «💰 Финансы», «🌿 Настроение», «🍀 Совет дня», «🔢 Число дня: n — короткое значение». Ясно, конкретно, без псевдоточности. Можно объединить финансы/настроение когда нельзя дать независимый смысл без воды.
- ~90–145 русских слов в среднем, НЕ искусственный лимит ради галочки; не превращать в 1-2 слова без пользы, не размножать одно действие в каждом абзаце; оставить серьёзную атмосферу Astra, с очень редкой спрятанной сатирой. Механика прогнозов важнее литературных украшательств.
- Новая extended -4 должна быть полезным дополнением: одна новая развилка, практический способ применить, символ/цвет и руна (традиция чётко отмечена), углубление числа и финальный совет Жирного; без нудных повторов бесплатной части и без самоплагиата.
- Поддержать единый \`formatFreeForecast\`/presentation helper для ручного чтения и будущего Cron (без изменения Cron в этой задаче). Кнопки — соседняя TASK_04.
