## Реализация в TASK 01 (без D1/Worker)
1. **Каталог** `src/tarot25/catalog.mjs` (или аналог с документированным API). Строго 78 явных объектов, 22 Major + 56 Minor; без динамической «генерации смыслов» из 8 общих фраз. У каждого:
  - `id`, `rws_order` или другое стабильное упорядочение, `arcana` (`major`/`minor`), `suit` (`wands`,`cups`,`swords`,`pentacles` либо null), `rank` (для minor), `name_ru`, `name_en`, `keywords`;
  - `upright`/`reversed`: самостоятельные качественные русские трактовки (не механические отрицания), `light`/`shadow`, осмысленное `advice`, поле `contexts` с по меньшей мере отношениями/делами/выбором/ресурсами/самонаблюдением;
  - `asset_id`/`alt_text` как будущие стабильные ссылки (изображений не добавлять и внешних URL не придумывать), `deck_version` явно; источники интерпретаций и рамки традиции в комментариях/отдельной редакционной справке.
  - точное наименование 22 Major согласно RWS, включая 0 Fool, VIII Strength, XI Justice; minor 14 рангов * 4 масти. Не путать Pages/Knights/Queens/Kings.
2. **Каталог раскладов** `src/tarot25/spreads.mjs`. Стабильные `spread_id`, `positions`, `theme`, `size`, `description`, полный и правильный набор 3 basic/3 thematic relations/work/choice/5/7/10 Celtic Cross. Десятикарточный крест с осмысленными десятью позициями. Ценовые поля в этом задании только документировать как ПРЕДЛОЖЕНИЕ: 5/8/14/21/32; никаких новых платных операций.
3. **Чистый движок** `src/tarot25/engine.mjs`. Функции для выбора уникальных карт без возвращения из 78 с криптографически качественным RNG; без modulo-bias (rejection sampling либо unbiased `getRandomValues`). Ориентации с независимым выбором. Передавать RNG/seed для воспроизводимых тестов, не пользоваться `Math.random` в боевом пути. Отдельно функции валидировать draw и строить связный структурированный текст (позиционные трактовки, связь пар/троек, общий синтез, 1–2 практических мягких совета; нейтральная тональность; не обещать будущее). В выдаче понятные названия карт, масть, число, прямое/перевёрнутое, позиции; для длинных раскладов абзацы читаемы. Учитывать безусловные лимиты Telegram 4096 символов через безопасный splitter без разрыва Unicode/callback text в будущем, но не вызывать Bot API сейчас.
4. **Контент**: качественные авторские трактовки на русском для каждой карты, без копирования чужих защищённых текстов. Базовые значения традиции можно использовать, но выражение авторское. Не смешивать научные астрономические расчёты с символикой.
5. **Версии/snapshots**: введи `deck_version='rws78-v1'`, `engine_version='tarot25-v1'` и версию расклада; создавай serializable `reading_snapshot` со списком `card_id`, `reversed`, `position_id`, `question` опционально, `text`, `created_at`, полными версиями. Функция render snapshot не вызывает RNG и не интерпретирует заново, а возвращает исходный текст. Будущая D1 интеграция — следующая задача.
6. **Не трогать**: `migrations/0021–0028`, `release/ASTRA_2_4_WORKER.js`, `scripts/build-2.4.mjs`, цену действующего Таро5, старые оплаченные records, кнопки/флаги, настройки Cron/Stars, существующие 22-card dayCard. Не включать данные колоды в Worker до отдельного согласованного интеграционного этапа.

## Обязательные тесты
- 78 unique IDs, 22 + 56, 4 suits × 14, RWS VIII/XI, рус/англ полные названия.
- Непустые, неповторяющиеся, осмысленные upright/reversed/advice/themes; не тестировать лишь строки `length>0`.
- Колода одной выдачи без дублей; ориентации имеют значения и 10-card не выходит за 78; RNG одинакового тестового ввода даёт воспроизводимый результат, независимые вероятности не упираются в `Math.random`.
- Валидация карт/позиций/версий и отказ на forged `card_id`, одинаковой карте, невозможной позиции, плохом question и giant text.
- Рендер старых снэпшотов байт-в-байт идентичен, не пересчитывает карту и не требует внешней сети.
- 3/5/7/10 позиций и тематические 3; как минимум 20 сценариев синтеза, с картами противоположных значений, парой прямых/перевёрнутых, разными мастями; результаты не должны быть механической склейкой.
- Бюджет/performance CPU оценка на Node — честно указать, что это не реальные Cloudflare CPU10ms/D1.
- Запустить текущие регрессии TASK06 без изменения ожиданий и генерации посторонних tracked diff; при несовместимости отдельно задокументировать, но не ослаблять старые тесты.
- Предусмотреть будущие (D1)/paid smoke и 2.0→целевой release migration tests в TASK 02–04; их не считать пройденными сейчас.
