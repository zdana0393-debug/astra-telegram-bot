## Изменения и проверки

Импортёр теперь принимает несколько `--archive` и отдельный `--manifest` формата `astra-author-art-assets-v1`. Обязательны точные ID/asset_id, пути `cards/<card_id>.jpg`, SHA256, размеры и направления0/180. Проверяются дубли между частями, пропуски, лишние файлы, ZIP traversal/links/ограничения размера, дубли JSON-ключей и приватность output. Прежний embedded-manifest режим сохранён. Все операции локальные, rollback касается только нового промежуточного каталога.

Тестовая fixture может читать приватный manifest через `ASTRA_PRIVATE_TAROT_MANIFEST`; в Git нет настоящих изображений/реестра. Mock `file_id` остаются явно SYNTHETIC. Каждая модельная фото-отправка разрешается в реальный приватный JPEG и проверяет его SHA локально. Это проверяет связь выбранной карты/ориентации с файлом, **не доказывает приём Telegram**.
