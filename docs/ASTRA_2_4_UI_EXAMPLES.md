## Условия и явное хранение

```text
Условия Stars

Пыль — внутренний доступ к материалам, без вывода в деньги. Стоимость пакета фиксируется в заказе до счёта. Пыль начисляется только после подтверждённой оплаты Telegram.

При возврате уже выданные материалы не отзываются. Доступная пыль уменьшается на стоимость возвращённого пакета; недостаток становится явным долгом. Будущие начисления сначала погашают долг. Баланс не становится отрицательным.

Поддержка: mailto:support@example.test.
Версия условий: test-terms-v1.
Оплаченные заказы, charge ID и ID плательщика нужны для возвратов/споров: 365 дней после закрытия всех платёжных дел и погашения долга. Неразрешённые случаи сохраняются до завершения. После удаления персональных доказательств остаётся необратимый hash charge ID с суммой пакета и признаком возврата, без ID плательщика без ограничения срока для запрета повторного начисления. /delete не стирает незавершённые платежи/долги.

До согласования условий, контакта, хранения и окружения магазин выключен.
```
