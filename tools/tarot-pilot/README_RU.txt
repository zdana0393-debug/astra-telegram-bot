ASTRA — ПИЛОТ ОДНОЙ КАРТЫ, ТОЛЬКО ДВА СООБЩЕНИЯ

Это отдельный локальный инструмент для существующего бота @LaDa_Iskra_Opel_Astrabot.
Он не читает и не меняет Cloudflare, D1, webhook, Cron или баланс.
Нет getUpdates, платежей, массовой загрузки и автоматических повторов.

КАК ЗАПУСТИТЬ НА WINDOWS
1. Сохраните полученный приватный ZIP на свой компьютер.
2. Правой кнопкой по ZIP → «Извлечь всё». Не запускайте файлы прямо внутри ZIP.
3. В извлечённой папке дважды нажмите START_WINDOWS.cmd.
   Требуется обычный Python3.10+ с Tcl/Tk (стандартный установщик Python для Windows).
   Если Python отсутствует, окно объяснит установку с python.org; ничего в API не отправится.
   Дополнительных Python-библиотек устанавливать не нужно.

В окне введите свой числовой Telegram ID и отметьте, что сами проверили его.
Кнопка «Где посмотреть мой ID?» даёт инструкцию Telegram Desktop.
В экспортированном account-information JSON это personal_information → user_id.
Номер телефона, username и ID бота вместо своего ID не подходят.
Полный экспорт не пересылайте: нужен только ваш собственный ID.

ТОКЕН
Введите УЖЕ СОХРАНЁННЫЙ действующий токен этого бота в скрытое поле окна.
Он не передаётся ChatGPT и не сохраняется в файлы/журнал/командную строку.
Допустима заранее настроенная локальная переменная ASTRA_PILOT_BOT_TOKEN.
Для новичка рекомендуем скрытое поле, без команд настройки окружения.
НЕ присылайте токен в чат, GitHub, сообщения, скриншоты или отчёты.
НЕ отзывайте и НЕ перевыпускайте токен: это может остановить действующего бота.
Если сохранённого токена нет — STOP, не меняйте настройки основного бота.

ПРОВЕРКА И ОКОНЧАТЕЛЬНОЕ РАЗРЕШЕНИЕ
Открытие окна не обращается к сети.
«Проверить бота и адресата — без сообщений» делает только getMe и getChat.
Проверяются bot_id/username и ваш положительный chat_id/type=private.
При проблемах прямого HTTPS-доступа к api.telegram.org инструмент остановится:
он не использует прокси, не отключает проверку TLS и не следует перенаправлениям.
Сам тип private не доказывает принадлежность аккаунта вам — поэтому ID надо
сначала проверить самостоятельно и затем сверить имя и ID в окне подтверждения.

Дальше отдельное окно покажет адресата, bot_id/chat_id и ровно два действия.
Кнопка по умолчанию «Нет». Если имя/ID не ваши — отмените.
Только после «Да»:
  1. sendPhoto с прямым THE FOOL из приватного пакета, после проверки SHA256;
  2. сохранение ACK/file_id вне Git, пауза2сек и sendPhoto по полученному file_id.
Получатель фиксирован, третья отправка блокируется. Оба ACK должны содержать
правильные bot_id/chat_id, разные message_id и ту же file_unique_id/геометрию фото.
Токен никогда не записывается в журнал; фото Telegram может перекодировать.
protect_content ограничивает обычную пересылку, но не скриншоты.

ПРИВАТНЫЙ РЕЕСТР И ОШИБКИ
На Windows журнал: %LOCALAPPDATA%\Astra25Pilot\pilot.json.
Это личная папка вашего Windows-пользователя; не перемещайте реестр в Git/общую папку.
При каждом ACK он атомарно обновляется. После первого фото file_id сохраняется
ДО второго запроса. При дисковой ошибке второе сообщение не отправляется.
Если случились 400/403/429/5xx, timeout, неверный ACK или прерывание — STOP.
Telegram мог уже принять сообщение; автоматического повтора нет.
Повторный запуск при существующем pilot.json блокируется. Не удаляйте журнал
для повторной попытки без проверки чата и отдельного решения владельца.

ПОСЛЕ ПИЛОТА
При успехе окно покажет два message_id. Дальнейших отправок нет.
Для отчёта достаточно результата/двух message_id; сам приватный реестр/file_id
публиковать не нужно. Массовая загрузка и обновление2.0→2.5 — отдельное разрешение.

ПРОВЕРКИ ПОДГОТОВКИ
Ядро проверяется unittest с поддельным транспортом; реальных API-вызовов при
подготовке0;32 автоматических теста пройдены. Импорт GUI и синтаксис проверены локально. Настоящий Windows,
нативный Windows-launcher и Telegram пока NOT_TESTED; это подготовленный пилот,
не отчёт об успешной реальной отправке.

Публичные исходники инструмента не содержат фото/личных ID/токенов.
Выданный вам ZIP содержит вашу карту и приватный SHA-manifest: не добавляйте ZIP
или его содержимое в публичный GitHub. Это частный пакет для вашего компьютера.
