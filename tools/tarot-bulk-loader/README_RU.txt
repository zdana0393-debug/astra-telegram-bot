АСТРА — ГОТОВЫЙ WINDOWS-ЗАГРУЗЧИК78 КАРТ /156 ИЗОБРАЖЕНИЙ

Существующий бот, только подтверждённый личный чат владельца.
Без каналов, новых ботов, D1, Worker, webhook, Cron, платежей или пыли.
Этот код не разрешает реальную отправку без подтверждения адресата и объёма.

Скачайте ZIP опубликованной ветки с GitHub → «Извлечь всё».
В извлечённом репозитории откройте tools\tarot-bulk-loader\START_WINDOWS.cmd.
Не переносите эту папку отдельно: рядом в репозитории нужны прежний pilot_core,
проверенный импортёр scripts/import-tarot-art-private.py и ID-контракт из data/.
Нужен Python3.11+ с Tcl/Tk: Pillow13 не поддерживает Python3.10. Если для пилота
был установлен Python3.10, установите более новый обычным установщиком Python.

ВЫБОР ФАЙЛОВ
Кнопками выберите свой manifest.json и оба ZIP Part_01/Part_02.
PNG не нужны. ZIP не распаковывайте и JSON не редактируйте.
pilot.json автоматически ищется в личной папке прежнего пилота. Если не найден,
выберите его кнопкой; это необязательно, но успешный Шут даст минус1 загрузку.
Если успешный пилот подставил ваш chat_id — всё равно проверьте его и отметьте
«Этот ID принадлежит моему личному аккаунту». Токен вводится скрыто; он не сохраняется.
Не присылайте token/pilot.json/реестр в GitHub или публичный чат и не меняйте token.

ЛОКАЛЬНАЯ ПОДГОТОВКА
Если Pillow13.0.0 отсутствует, нажмите кнопку установки поддержки изображений.
Она с отдельным подтверждением установит пакет с официального PyPI без команд.
После установки перезапустите окно. Затем «Подготовить колоду локально».
Прежний проверенный импортёр подготовит156 JPEG в личной папке Windows.
Проверяются только выбранные новые входы; при повторном запуске готовый кэш
используется без повторной переработки78 карт. Перед каждой отправкой проверяется
SHA ровно отправляемого JPEG. Карты не загружаются на этапе подготовки.

ПРОВЕРКА И РЕАЛЬНОЕ РАЗРЕШЕНИЕ
Кнопка «Проверить адресата / продолжить» сначала вызывает только getMe/getChat.
Проверяются прежний бот, bot_id, ваш положительный ID и private-тип чата.
Затем окно показывает имя/chat_id и точное число НОВЫХ фотографий:
обычно155 при принятом pilot.json либо156 без него. Подтверждение по умолчанию «Нет».
Только после вашего «Да» загрузчик отправляет фотографии. Других получателей нет.
При открытии программы автоматических API-вызовов нет.

ПРОГРЕСС И ПЕРЕРЫВ
Полоса/счётчик показывают подтверждённое M/156. Интервал не меньше2сек, без параллели.
Лимиты общие с действующим ботом; ответ429 приостанавливает очередь на retry_after
плюс запас. Три ответа429 за один проход останавливают его до следующего продолжения.
Кнопка остановки ждёт текущий запрос/сохранение ACK; после этого окно можно закрыть.
Подтверждённое не отправляется повторно. После перезапуска выберите файлы,
подготовьте кэш и снова подтвердите адресата/оставшийся объём.

СЕТЕВОЙ СБОЙ / ПРИНУДИТЕЛЬНОЕ ЗАКРЫТИЕ
До каждого HTTP-запроса атомарно сохраняется sending. После ACK — file_id,
file_unique_id, message_id, SHA, card_id/ориентация и привязка к bot_id/chat_id.
Если ACK потерялся/диск отказал/процесс прерван, исход становится unknown.
Автоматически переотправлять такую карту нельзя; очередь остановится.
Кнопка «Разобрать неизвестную отправку» покажет одну карту. Проверьте её подпись
в личном чате. Только если вы явно разрешаете дополнительное сообщение этой
карты (возможен дубль), кнопка разрешит повтор; затем запуск отдельным продолжением.
Не удаляйте bulk-state.json, чтобы «начать заново». Исходный журнал попыток сохраняется.
Это не exactly-once Telegram: неизвестный приём невозможно доказать без ACK.

РЕЗУЛЬТАТЫ ТОЛЬКО В ЛИЧНОЙ ПАПКЕ
%LOCALAPPDATA%\Astra25DeckLoader\bulk-state.json — checkpoint/ACK/попытки.
%LOCALAPPDATA%\Astra25DeckLoader\telegram-registry.json — только после156 подтверждений.
assets\... — локальные файлы/manifest, без публичного image-hosting.
Итог проверяется:78 card_id, по2 ориентации,156 корректных уникальных file_id,
один существующий бот, realm production. Формат готов для прежнего приватного
сборщика scripts/build-tarot-art-private.mjs. Worker автоматически не устанавливается.
Сохраните личную резервную копию этой папки: file_id не восстановить из JPEG.
Токен в неё не входит. Protect_content не предотвращает скриншоты получателя.

ПИЛОТ
Импортируется только completed pilot.json с двумя подтверждениями именно этого
бота/чата, той же прямой картой Шута/SHA/art_version. Если файл неправильный — STOP.
Его можно отключить отдельной кнопкой: окно честно покажет156 новых сообщений.

ЗАЩИТА
ОС-блокировка исключает два одновременно работающих загрузчика; при аварии
процесса блокировка освобождается системой, а неизвестные отправки остаются в журнале.
При сбое сохранения ACK следующая карта не отправляется. Переключить chat_id/bot
в существующем журнале нельзя. Нет getUpdates и изменений настроек основного бота.
Локальные автоматические тесты используют fake Telegram и синтетические байты.
Реальную Windows GUI/пакетную загрузку нужно принять на компьютере владельца.
